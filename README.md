# CareerBridge AI 🌉

An AI-powered career guidance assistant built for professionals — especially women — returning to the workforce after a career break.

## Problem
Returning to work after a career break can feel overwhelming. Many professionals struggle to identify how their existing skills translate to today's job market, what gaps they need to fill, and which roles to target.

## Solution
CareerBridge AI takes a user's experience, career gap duration, industry background, and skills, and uses Google Gemini to generate personalized, structured career guidance covering:
- Key strengths
- Skill gaps to address
- Relevant job roles to target

## Built With
- **Google Gemini API** (via Google AI Studio) — gemini-3-flash-preview model
- **Python**
- **Gradio** — for the interactive user interface
- **Google Colab** — development environment

## How to Run
1. Open `careerbridge_ai.ipynb` in Google Colab
2. Add your Gemini API key as a Colab secret named `GEMINI_API_KEY`
3. Run all cells in order
4. Use the Gradio interface to input your background and get personalized career advice
